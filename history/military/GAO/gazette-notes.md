# The Gazette

[The Gazette](https://www.thegazette.co.uk/about) is the UK's official public record.

One problem with searching the Gazette is that it's text index relies on OCR which is not always reliable.
The name you're searching for might appear in an issue of the Gazette but not be identified by the system.

I've selectively transcribed bits of War Office notices, and I'd like to make this data re-usable, so I'm capturing [Gazette transcripts](gazette.xhtml) as XHTML with semantic mark-up.
